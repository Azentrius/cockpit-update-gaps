# Update Gaps

A [Cockpit](https://cockpit-project.org/) add-on that shows, per server, where updates are missing
although Cockpit's “Software Updates” lists none: held packages, fixes that only come with Ubuntu Pro,
pending restarts, stale or missing package lists, sources that automatic updates leave out, and
software outside the package manager. For every finding it says where the information comes from, why
“Software Updates” does not show it and what you can do. The add-on only reads; it changes nothing on
the system.

Work in progress: the first release, 0.1.0, is not out yet.
